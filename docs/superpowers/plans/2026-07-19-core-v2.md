# Core v2 (Dispatcher + ConversationRuntime) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar el motor de flows por steps y el MessageRouter por un ConversationRuntime async/await + Dispatcher con consumo-por-defecto, con suite de tests sobre MockProvider.

**Architecture:** Un solo runtime de conversación basado en promesas suspendidas por chat-key; el DSL `flow()` compila a pasos que un intérprete ejecuta con las mismas primitivas. Un Dispatcher serializado por chat decide en orden estricto: comandos → conversación activa → matchers por especificidad → catch-all. Spec: `docs/superpowers/specs/2026-07-19-core-v2-design.md`.

**Tech Stack:** TypeScript (tsc, module NodeNext, ESM-only), Node ≥ 20, `@whiskeysockets/baileys` 7.0.0-rc13 (pin exacto), vitest, pino.

```ts
// src/core/matching.ts
import type { Trigger, TriggerObject, MatchStrategy } from './types.js'

export function normalizeText(s: string): string {
  return s
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/\s+/g, ' ')
    .trim()
}

interface MatchInput { body: string; isGroup: boolean }

function isTriggerObject(t: Trigger): t is TriggerObject {
  return typeof t === 'object' && t !== null && !(t instanceof RegExp) && !Array.isArray(t) && 'pattern' in t
}

export function matchTrigger(trigger: Trigger, ctx: MatchInput): boolean {
  if (typeof trigger === 'function') return trigger(ctx)

  const obj: TriggerObject = isTriggerObject(trigger) ? trigger : { pattern: trigger as TriggerObject['pattern'] }
  const scope = obj.scope ?? 'all'
  if (scope === 'dm' && ctx.isGroup) return false
  if (scope === 'group' && !ctx.isGroup) return false

  const patterns = Array.isArray(obj.pattern) ? obj.pattern : [obj.pattern]
  const strategy: MatchStrategy = obj.match ?? 'equals'
  const body = normalizeText(ctx.body ?? '')

  return patterns.some((p) => {
    if (p instanceof RegExp) return p.test(ctx.body ?? '')
    const text = normalizeText(String(p))
    switch (strategy) {
      case 'contains': return body.includes(text)
      case 'startsWith': return body.startsWith(text)
      case 'endsWith': return body.endsWith(text)
      case 'equals':
      default: return body === text
    }
  })
}

export function triggerSpecificity(trigger: Trigger): number {
  if (typeof trigger === 'function') return 5
  if (trigger instanceof RegExp) return 20
  if (Array.isArray(trigger)) return Math.max(...trigger.map((p) => triggerSpecificity(p)))
  if (isTriggerObject(trigger)) {
    const hasRegex = (Array.isArray(trigger.pattern) ? trigger.pattern : [trigger.pattern]).some((p) => p instanceof RegExp)
    if (hasRegex) return 20
    switch (trigger.match ?? 'equals') {
      case 'equals': return 40
      case 'startsWith': return 30
      case 'endsWith': return 25
      case 'contains': return 10
    }
  }
  return 40 // string plano = equals
}
```

```ts
// src/utils/duration.ts
const UNITS: Record<string, number> = { ms: 1, s: 1000, m: 60_000, h: 3_600_000 }

/** Parse '500ms' | '90s' | '2m' | '1h' | number(ms) → milliseconds. */
export function parseDuration(d: string | number): number {
  if (typeof d === 'number') return d
  const m = /^(\d+(?:\.\d+)?)\s*(ms|s|m|h)$/.exec(d.trim())
  if (!m) throw new Error(`Invalid duration: "${d}" — use e.g. '30s', '2m', '1h' or milliseconds`)
  return Math.round(parseFloat(m[1]) * UNITS[m[2]])
}
```

`ConversationControls` se implementa en Task 3; en este task `enter` invoca `fn` con un stub de controls que solo tiene `wait`-passthrough — el task 3 lo completa. Para evitar doble trabajo: **este task define `ConversationControls` como interfaz mínima `{ waitAny(opts?): Promise<RuntimeMessage>; say(t: string): Promise<void>; state: Record<string, unknown>; end(msg?): never }` y Task 3 la extiende.**

Semántica exacta:
- `enter`: si ya hay activa para la key, la aborta primero. Crea `{ key, state: {}, inbox: [], pending: undefined }`. Ejecuta `fn`; captura señales: `ConversationEnded` → si `farewell`, `ctx.reply(farewell)`; `ConversationGoto` → cleanup y `enter(target)`; `ConversationTimeout` → reply `timeoutMessage`; `ConversationCancelled` → reply `cancelledMessage` solo si reason lo indica; `RetriesExceeded` → reply `retriesMessage`; otro error → `onError` + reply `errorMessage`. Siempre cleanup en finally (timers, pending, entry).
- `wait`: si inbox no vacío → shift y resolve inmediato. Si no, guarda pending `{ resolve, reject, filter }` y arma timer con `timeoutMs` (default config). Timer → reject `ConversationTimeout`.
- `deliver`: sin activa → false. Con pending: si `pending.filter` existe y rechaza → false (pipeline sigue). Si no → resolve(ctx), true. Sin pending (conversación procesando): push a inbox (cap 10, drop oldest), true.
- `abort`: rechaza pending con `ConversationCancelled`; si no hay pending, marca flag `cancelled` que el próximo `wait` lanza de inmediato.

```ts
// src/conversations/ConversationRuntime.ts
import {
  ConversationCancelled, ConversationEnded, ConversationGoto,
  ConversationTimeout, RetriesExceeded,
} from './errors.js'

export interface RuntimeMessage {
  from: string; sender: string; body: string; type: string; isGroup: boolean
  reply(text: string): Promise<unknown>
}

export interface ResolvedWaitOptions {
  timeoutMs?: number
  filter?: (ctx: RuntimeMessage) => boolean
}

/** Interfaz mínima; controls.ts (Task 3) la extiende con ask/waitText/choose/... */
export interface ConversationControlsBase {
  waitAny(opts?: ResolvedWaitOptions): Promise<RuntimeMessage>
  say(text: string): Promise<void>
  state: Record<string, unknown>
  end(farewell?: string): never
}

export type ConversationFn<C extends ConversationControlsBase = ConversationControlsBase> =
  (c: C, ctx: RuntimeMessage) => Promise<void>

export interface RuntimeConfig {
  defaultTimeoutMs?: number
  timeoutMessage?: string
  cancelledMessage?: string
  retriesMessage?: string
  errorMessage?: string
  scope?: 'participant' | 'chat'
  logger?: { debug?: (...a: unknown[]) => void; warn?: (...a: unknown[]) => void; error?: (...a: unknown[]) => void }
  onError?: (error: unknown, ctx: RuntimeMessage) => void
  /** Task 3 inyecta la factory completa de controls; default = base. */
  controlsFactory?: (rt: ConversationRuntime, key: string, ctx: RuntimeMessage) => ConversationControlsBase
}

interface PendingWait {
  resolve(ctx: RuntimeMessage): void
  reject(err: Error): void
  filter?: (ctx: RuntimeMessage) => boolean
  timer?: NodeJS.Timeout
}

interface ActiveConversation {
  key: string
  state: Record<string, unknown>
  inbox: RuntimeMessage[]
  pending?: PendingWait
  cancelled?: ConversationCancelled
}

const INBOX_CAP = 10

export class ConversationRuntime {
  private registry = new Map<string, ConversationFn>()
  private active = new Map<string, ActiveConversation>()

  constructor(private cfg: RuntimeConfig = {}) {}

  register(name: string, fn: ConversationFn): void { this.registry.set(name, fn) }
  has(name: string): boolean { return this.registry.has(name) }

  keyFor(ctx: Pick<RuntimeMessage, 'from' | 'sender' | 'isGroup'>): string {
    const scope = this.cfg.scope ?? 'participant'
    return ctx.isGroup && scope === 'participant' ? `${ctx.from}:${ctx.sender}` : ctx.from
  }

  hasActive(key: string): boolean { return this.active.has(key) }

  async enter(nameOrFn: string | ConversationFn, ctx: RuntimeMessage): Promise<void> {
    const fn = typeof nameOrFn === 'string' ? this.registry.get(nameOrFn) : nameOrFn
    if (!fn) throw new Error(`Conversation "${String(nameOrFn)}" is not registered`)

    const key = this.keyFor(ctx)
    if (this.active.has(key)) this.abort(key)

    const entry: ActiveConversation = { key, state: {}, inbox: [] }
    this.active.set(key, entry)

    const controls = (this.cfg.controlsFactory ?? defaultControlsFactory)(this, key, ctx)

    let goto: ConversationGoto | undefined
    try {
      await fn(controls as never, ctx)
    } catch (e) {
      if (e instanceof ConversationEnded) {
        if (e.farewell) await this.safeReply(ctx, e.farewell)
      } else if (e instanceof ConversationGoto) {
        goto = e
      } else if (e instanceof ConversationTimeout) {
        await this.safeReply(ctx, this.cfg.timeoutMessage ?? '⏰ La conversación expiró por inactividad.')
      } else if (e instanceof ConversationCancelled) {
        if (!e.silent && this.cfg.cancelledMessage) await this.safeReply(ctx, this.cfg.cancelledMessage)
      } else if (e instanceof RetriesExceeded) {
        await this.safeReply(ctx, this.cfg.retriesMessage ?? '❌ Demasiados intentos. Conversación terminada.')
      } else {
        this.cfg.onError?.(e, ctx)
        this.cfg.logger?.error?.('conversation error', e)
        await this.safeReply(ctx, this.cfg.errorMessage ?? '⚠️ Ocurrió un error. La conversación terminó.')
      }
    } finally {
      this.cleanup(key)
    }
    if (goto) await this.enter(goto.target, ctx)
  }

  deliver(ctx: RuntimeMessage): boolean {
    const entry = this.active.get(this.keyFor(ctx))
    if (!entry) return false
    if (entry.pending) {
      if (entry.pending.filter && !entry.pending.filter(ctx)) return false
      entry.pending.resolve(ctx)
      return true
    }
    entry.inbox.push(ctx)
    if (entry.inbox.length > INBOX_CAP) entry.inbox.shift()
    return true
  }

  abort(key: string, _reason?: string): boolean {
    const entry = this.active.get(key)
    if (!entry) return false
    const cancel = new ConversationCancelled(true)
    if (entry.pending) entry.pending.reject(cancel)
    else entry.cancelled = cancel
    return true
  }

  /** Usado por controls. */
  wait(key: string, opts: ResolvedWaitOptions = {}): Promise<RuntimeMessage> {
    const entry = this.active.get(key)
    if (!entry) return Promise.reject(new ConversationCancelled(true))
    if (entry.cancelled) return Promise.reject(entry.cancelled)
    const queued = opts.filter ? undefined : entry.inbox.shift()
    if (queued) return Promise.resolve(queued)

    return new Promise<RuntimeMessage>((resolve, reject) => {
      const timeoutMs = opts.timeoutMs ?? this.cfg.defaultTimeoutMs ?? 300_000
      const timer = timeoutMs > 0
        ? setTimeout(() => { entry.pending = undefined; reject(new ConversationTimeout()) }, timeoutMs)
        : undefined
      entry.pending = {
        filter: opts.filter,
        resolve: (ctx) => { if (timer) clearTimeout(timer); entry.pending = undefined; resolve(ctx) },
        reject: (err) => { if (timer) clearTimeout(timer); entry.pending = undefined; reject(err) },
        timer,
      }
    })
  }

  getState(key: string): Record<string, unknown> | undefined { return this.active.get(key)?.state }

  private cleanup(key: string): void {
    const entry = this.active.get(key)
    if (entry?.pending?.timer) clearTimeout(entry.pending.timer)
    this.active.delete(key)
  }

  private async safeReply(ctx: RuntimeMessage, text: string): Promise<void> {
    try { await ctx.reply(text) } catch (e) { this.cfg.logger?.warn?.('reply failed', e) }
  }
}

function defaultControlsFactory(rt: ConversationRuntime, key: string, ctx: RuntimeMessage): ConversationControlsBase {
  return {
    waitAny: (opts) => rt.wait(key, opts ?? {}),
    say: async (text) => { await ctx.reply(text) },
    state: rt.getState(key) ?? {},
    end: (farewell) => { throw new ConversationEnded(farewell) },
  }
}
```

```ts
// src/conversations/controls.ts
import type { ConversationRuntime, RuntimeMessage, ConversationControlsBase } from './ConversationRuntime.js'
import { ConversationEnded, ConversationGoto, RetriesExceeded } from './errors.js'
import { parseDuration } from '../utils/duration.js'
import { normalizeText } from '../core/matching.js'
import type { WaitOptions } from '../core/types.js'

const MEDIA_TYPES = ['image', 'video', 'audio', 'document', 'sticker'] as const
type MediaType = (typeof MEDIA_TYPES)[number]

export interface ConversationControls extends ConversationControlsBase {
  ask(text: string, opts?: WaitOptions): Promise<string>
  waitText(opts?: WaitOptions): Promise<string>
  waitMedia(types?: MediaType[], opts?: WaitOptions): Promise<RuntimeMessage>
  choose(prompt: string, options: Record<string, string>, opts?: WaitOptions): Promise<string>
  goto(name: string, args?: unknown): never
}

export function createControls(rt: ConversationRuntime, key: string, ctx: RuntimeMessage): ConversationControls {
  const timeoutOf = (o?: WaitOptions) => (o?.timeout !== undefined ? parseDuration(o.timeout) : undefined)

  const rawWait = (o?: WaitOptions) => rt.wait(key, { timeoutMs: timeoutOf(o), filter: o?.filter })

  async function loopWait<T>(
    opts: WaitOptions | undefined,
    accept: (m: RuntimeMessage) => Promise<{ ok: true; value: T } | { ok: false; message: string }>,
  ): Promise<T> {
    const retries = opts?.retries ?? 3
    let attempts = 0
    for (;;) {
      const m = await rawWait(opts)
      const r = await accept(m)
      if (r.ok) return r.value
      attempts++
      if (attempts >= retries) throw new RetriesExceeded()
      await ctx.reply(r.message)
    }
  }

  const controls: ConversationControls = {
    say: async (text) => { await ctx.reply(text) },
    state: rt.getState(key) ?? {},
    end: (farewell) => { throw new ConversationEnded(farewell) },
    goto: (name, args) => { throw new ConversationGoto(name, args) },
    waitAny: (o) => rawWait(o as WaitOptions),

    waitText: (opts) => loopWait<string>(opts, async (m) => {
      if (m.type !== 'text') return { ok: false, message: opts?.otherwise ?? '✍️ Escribe tu respuesta como texto.' }
      const v = opts?.validate ? await opts.validate(m.body, m) : true
      return v === true
        ? { ok: true, value: m.body }
        : { ok: false, message: typeof v === 'string' ? v : '❌ Entrada inválida, intenta de nuevo.' }
    }),

    ask: async (text, opts) => { await ctx.reply(text); return controls.waitText(opts) },

    waitMedia: (types = [...MEDIA_TYPES], opts) => loopWait<RuntimeMessage>(opts, async (m) => {
      return (types as string[]).includes(m.type)
        ? { ok: true, value: m }
        : { ok: false, message: opts?.otherwise ?? '📎 Envía un archivo válido.' }
    }),

    choose: async (prompt, options, opts) => {
      const keys = Object.keys(options)
      const menu = `${prompt}\n\n${keys.map((k, i) => `${i + 1}) ${options[k]}`).join('\n')}`
      await ctx.reply(menu)
      return loopWait<string>(opts, async (m) => {
        const body = normalizeText(m.body)
        const byIndex = /^\d+$/.test(body) ? keys[parseInt(body, 10) - 1] : undefined
        const byKey = keys.find((k) => normalizeText(k) === body)
        const byLabel = keys.find((k) => normalizeText(options[k]) === body)
        const picked = byIndex ?? byKey ?? byLabel
        return picked
          ? { ok: true, value: picked }
          : { ok: false, message: opts?.otherwise ?? menu }
      })
    },
  }
  return controls
}
```

```ts
import type { Trigger, TriggerScope, WaitOptions } from '../core/types.js'
import type { RuntimeMessage } from '../conversations/ConversationRuntime.js'
import type { ConversationControls } from '../conversations/controls.js'
import { normalizeText } from '../core/matching.js'
import { parseDuration } from '../utils/duration.js'

export type DynamicText = (ctx: RuntimeMessage, c: ConversationControls) => string | Promise<string>
export type FlowAction = (ctx: RuntimeMessage, c: ConversationControls) => unknown | Promise<unknown>

export type CompiledStep =
  | { kind: 'say'; text: string | DynamicText }
  | { kind: 'ask'; text: string | DynamicText; stateKey: string; opts?: WaitOptions }
  | { kind: 'do'; fn: FlowAction }
  | { kind: 'choose'; prompt: string; options: Record<string, { label: string; then?: CompiledFlow | FlowAction }>; opts?: WaitOptions }
  | { kind: 'goto'; target: string }

export interface CompiledFlow {
  id: string
  trigger: Trigger
  steps: CompiledStep[]
  opts: { timeoutMs?: number; persistent?: boolean; scope?: TriggerScope }
}

export function isCompiledFlow(x: unknown): x is CompiledFlow {
  return typeof x === 'object' && x !== null && 'steps' in x && 'trigger' in x && 'id' in x
}

export function flow(trigger: Trigger): FlowBuilder { return new FlowBuilder(trigger) }
/** Alias para migración desde bot-whatsapp/BuilderBot. */
export const addKeyword = flow

export class FlowBuilder {
  private steps: CompiledStep[] = []
  private _id?: string
  private _timeoutMs?: number
  private _persistent = false
  private _scope?: TriggerScope

  constructor(private trigger: Trigger) {}

  say(text: string | DynamicText): this { this.steps.push({ kind: 'say', text }); return this }

  ask(text: string | DynamicText, stateKey: string, opts?: WaitOptions): this {
    this.steps.push({ kind: 'ask', text, stateKey, opts }); return this
  }

  do(fn: FlowAction): this { this.steps.push({ kind: 'do', fn }); return this }

  media(source: string, caption?: string): this {
    this.steps.push({ kind: 'do', fn: async (ctx) => { await (ctx as RuntimeMessage & { photo?(s: string, c?: string): Promise<unknown> }).photo?.(source, caption) } })
    return this
  }

  choose(prompt: string, options: Record<string, string | { label: string; then?: FlowBuilder | CompiledFlow | FlowAction }>): this {
    const compiled: Record<string, { label: string; then?: CompiledFlow | FlowAction }> = {}
    for (const [key, value] of Object.entries(options)) {
      if (typeof value === 'string') compiled[key] = { label: value }
      else compiled[key] = {
        label: value.label,
        then: value.then instanceof FlowBuilder ? value.then.compile() : value.then,
      }
    }
    this.steps.push({ kind: 'choose', prompt, options: compiled })
    return this
  }

  goto(target: string | FlowBuilder): this {
    this.steps.push({ kind: 'goto', target: typeof target === 'string' ? target : target.compile().id })
    return this
  }

  timeout(d: string | number): this { this._timeoutMs = parseDuration(d); return this }
  persistent(): this { this._persistent = true; return this }
  scope(s: TriggerScope): this { this._scope = s; return this }
  id(explicit: string): this { this._id = explicit; return this }

  compile(): CompiledFlow {
    const id = this._id ?? deriveId(this.trigger)
    if (!id) {
      if (this._persistent) throw new Error('persistent() flows need a string trigger or an explicit .id("name")')
    }
    return {
      id: id ?? `flow_${Math.abs(hashSteps(this.steps))}`,
      trigger: this.trigger,
      steps: this.steps,
      opts: { timeoutMs: this._timeoutMs, persistent: this._persistent, scope: this._scope },
    }
  }
}

function deriveId(trigger: Trigger): string | undefined {
  if (typeof trigger === 'string') return normalizeText(trigger)
  if (Array.isArray(trigger)) {
    const s = trigger.find((t): t is string => typeof t === 'string')
    return s ? normalizeText(s) : undefined
  }
  if (typeof trigger === 'object' && trigger !== null && !(trigger instanceof RegExp) && 'pattern' in trigger) {
    return deriveId(trigger.pattern as Trigger)
  }
  return undefined
}

function hashSteps(steps: CompiledStep[]): number {
  const s = steps.map((x) => x.kind).join('|')
  let h = 0
  for (let i = 0; i < s.length; i++) h = (h * 31 + s.charCodeAt(i)) | 0
  return h
}
```

```ts
// src/conversations/interpreter.ts
import type { CompiledFlow, CompiledStep, FlowAction } from '../flows/FlowBuilder.js'
import { isCompiledFlow } from '../flows/FlowBuilder.js'
import type { ConversationFn, RuntimeMessage } from './ConversationRuntime.js'
import type { ConversationControls } from './controls.js'
import { ConversationGoto } from './errors.js'

async function resolveText(t: CompiledStep & { kind: 'say' | 'ask' }, ctx: RuntimeMessage, c: ConversationControls): Promise<string> {
  return typeof t.text === 'function' ? await t.text(ctx, c) : t.text
}

export async function runSteps(
  flow: CompiledFlow,
  ctx: RuntimeMessage,
  c: ConversationControls,
  startAt = 0,
  onStepDone?: (stepIndex: number) => Promise<void>,   // hook de checkpoint (Task 5)
): Promise<void> {
  for (let i = startAt; i < flow.steps.length; i++) {
    const step = flow.steps[i]
    switch (step.kind) {
      case 'say':
        await c.say(await resolveText(step, ctx, c))
        break
      case 'ask': {
        const text = await resolveText(step, ctx, c)
        const answer = await c.ask(text, { timeout: flow.opts.timeoutMs, ...step.opts })
        c.state[step.stateKey] = answer
        break
      }
      case 'do':
        await step.fn(ctx, c)
        break
      case 'choose': {
        const labels = Object.fromEntries(Object.entries(step.options).map(([k, v]) => [k, v.label]))
        const picked = await c.choose(step.prompt, labels, { timeout: flow.opts.timeoutMs, ...step.opts })
        const then = step.options[picked]?.then
        if (isCompiledFlow(then)) await runSteps(then, ctx, c, 0, undefined)   // sub-flow y RETORNA al padre
        else if (typeof then === 'function') await (then as FlowAction)(ctx, c)
        break
      }
      case 'goto':
        throw new ConversationGoto(step.target)
    }
    if (onStepDone) await onStepDone(i)
  }
}

export function flowToConversation(flow: CompiledFlow): ConversationFn {
  return async (c, ctx) => { await runSteps(flow, ctx, c as ConversationControls) }
}
```

```ts
private compiled = new Map<string, CompiledFlow>()
private store?: CheckpointStore
private dormant = new Map<string, FlowCheckpoint>()

attachStore(store: CheckpointStore): void { this.store = store }

registerCompiled(flow: CompiledFlow): void {
  this.compiled.set(flow.id, flow)
  this.register(flow.id, this.wrapCompiled(flow))
}

private wrapCompiled(flow: CompiledFlow, startAt = 0): ConversationFn {
  if (!flow.opts.persistent || !this.store) {
    return startAt === 0 ? flowToConversation(flow) : async (c, ctx) => {
      await runSteps(flow, ctx, c as ConversationControls, startAt)
    }
  }
  return async (c, ctx) => {
    const key = this.keyFor(ctx)
    try {
      await runSteps(flow, ctx, c as ConversationControls, startAt, async (stepIndex) => {
        await this.store!.setCheckpoint(key, {
          flowId: flow.id, step: stepIndex + 1,
          state: { ...(c as ConversationControls).state },
          updatedAt: Date.now(),
        })
      })
    } finally {
      await this.store!.clearCheckpoint(key).catch(() => {})
    }
  }
}

  if (!this.store) return
  for (const [key, cp] of await this.store.listCheckpoints()) this.dormant.set(key, cp)
}

  const key = this.keyFor(ctx)
  const cp = this.dormant.get(key)
  if (!cp) return false
  this.dormant.delete(key)
  const flow = this.compiled.get(cp.flowId)
  if (!flow) { await this.store?.clearCheckpoint(key).catch(() => {}); return false }

    Object.assign((c as ConversationControlsBase).state, cp.state)
    await this.wrapCompiled(flow, cp.step)(c, rctx)
  }
  void this.enter(resumed, ctx)
  return true
```

Pipeline exacto dentro de `dispatch` (serializado por `runtime.keyFor(ctx)`):

1. `hooks.runBefore('message')` — false → fin.
2. Si `ctx.body` empieza con prefix: parsear `/cmd arg1 arg2`. Comando registrado → handler, fin. No registrado → `emit('command:unknown', { ctx, command })` y **continúa** (una conversación puede consumir "/xyz" como respuesta).
3. `runtime.deliver(ctx)` true → fin.
4. `await runtime.resumeDormant(ctx)` true → fin.
5. Matchers ordenados por `(specificity desc, seq asc)`: primer match ejecuta; si el handler llamó `ctx.pass()` → continuar con el siguiente; si no → fin.
6. catch-all en orden; misma regla de `pass()`.
7. `hooks.runAfter('message')` + `emit('message', ctx)` — SIEMPRE que no haya abortado el before-hook.
Errores en cualquier paso → `hooks.runError` + `emit('error', { error, ctx })`.

```ts
// src/core/Dispatcher.ts
import type { Trigger } from './types.js'
import { matchTrigger, triggerSpecificity, normalizeText } from './matching.js'
import type { ConversationRuntime, RuntimeMessage } from '../conversations/ConversationRuntime.js'

export interface DispatchContext extends RuntimeMessage {
  pass(): void
  abort(): void
  _passed?: boolean
  _aborted?: boolean
}
export type MessageHandler = (ctx: DispatchContext) => unknown | Promise<unknown>
export type CommandHandler = (ctx: DispatchContext, args: string[]) => unknown | Promise<unknown>

interface HooksLike {
  runBefore(event: string, ctx: unknown): Promise<boolean>
  runAfter(event: string, ctx: unknown): Promise<void>
  runError(event: string, ctx: unknown, err: unknown): Promise<void>
}

export interface DispatcherDeps {
  hooks: HooksLike
  runtime: ConversationRuntime
  commandPrefix?: string
  logger?: { debug?: (...a: unknown[]) => void; error?: (...a: unknown[]) => void }
  emit: (event: string, payload: unknown) => void
}

interface MatcherEntry { seq: number; trigger: Trigger; specificity: number; handler: MessageHandler }

export class Dispatcher {
  private commands = new Map<string, CommandHandler>()
  private matchers: MatcherEntry[] = []
  private catchAlls: MessageHandler[] = []
  private queues = new Map<string, Promise<void>>()
  private seq = 0

  constructor(private deps: DispatcherDeps) {}

  command(name: string, handler: CommandHandler): () => void {
    const key = normalizeText(name)
    this.commands.set(key, handler)
    return () => { this.commands.delete(key) }
  }

  matcher(trigger: Trigger, handler: MessageHandler, specificityOverride?: number): () => void {
    const entry: MatcherEntry = {
      seq: this.seq++,
      trigger,
      specificity: specificityOverride ?? triggerSpecificity(trigger),
      handler,
    }
    this.matchers.push(entry)
    this.matchers.sort((a, b) => b.specificity - a.specificity || a.seq - b.seq)
    return () => { this.matchers = this.matchers.filter((m) => m !== entry) }
  }

  onType(type: string, handler: MessageHandler): () => void {
    return this.matcher((c) => (c as unknown as DispatchContext).type === type, handler, 1)
  }

  catchAll(handler: MessageHandler): () => void {
    this.catchAlls.push(handler)
    return () => { this.catchAlls = this.catchAlls.filter((h) => h !== handler) }
  }

  /** Serializa por chat-key: nunca dos mensajes del mismo chat en paralelo. */
  dispatch(ctx: DispatchContext): Promise<void> {
    const key = this.deps.runtime.keyFor(ctx)
    const tail = this.queues.get(key) ?? Promise.resolve()
    const next = tail.then(() => this.run(ctx)).catch(() => {})
    this.queues.set(key, next)
    void next.finally(() => { if (this.queues.get(key) === next) this.queues.delete(key) })
    return next
  }

  private async run(ctx: DispatchContext): Promise<void> {
    const { hooks, runtime, emit } = this.deps
    const prefix = this.deps.commandPrefix ?? '/'
    try {
      if (!(await hooks.runBefore('message', ctx))) return

      // 1. comandos — SIEMPRE antes que la conversación activa
      if (ctx.body?.startsWith(prefix)) {
        const [raw, ...args] = ctx.body.slice(prefix.length).trim().split(/\s+/)
        const handler = this.commands.get(normalizeText(raw ?? ''))
        if (handler) {
          await handler(ctx, args)
          return this.finish(ctx)
        }
        emit('command:unknown', { ctx, command: raw })
        // continúa: una conversación puede consumir "/xyz" como texto
      }

      // 2. conversación activa
      if (runtime.deliver(ctx)) return this.finish(ctx)

      // 3. checkpoint dormido
      if (await runtime.resumeDormant(ctx)) return this.finish(ctx)

      // 4. matchers por especificidad
      for (const m of this.matchers) {
        if (!matchTrigger(m.trigger, ctx)) continue
        ctx._passed = false
        await m.handler(ctx)
        if (ctx._aborted) return this.finish(ctx)
        if (!ctx._passed) return this.finish(ctx)
      }

      // 5. catch-all
      for (const h of this.catchAlls) {
        ctx._passed = false
        await h(ctx)
        if (ctx._aborted || !ctx._passed) break
      }
      return this.finish(ctx)
    } catch (error) {
      this.deps.logger?.error?.('dispatch error', error)
      await hooks.runError('message', ctx, error)
      emit('error', { error, ctx })
    }
  }

  private async finish(ctx: DispatchContext): Promise<void> {
    await this.deps.hooks.runAfter('message', ctx)
    this.deps.emit('message', ctx)
  }
}
```

Nota `onType`: se registra como matcher-función con specificity 1 — así los type handlers participan del MISMO orden consumidor (spec §4).

```ts
plug(plugin: Plugin, config?: Record<string, unknown>): () => void {
  const spec = typeof plugin === 'function' ? plugin(config) : plugin
  const disposables: Array<() => void> = []
  const track = <A extends unknown[]>(fn: (...a: A) => () => void) =>
    (...a: A) => { const un = fn(...a); disposables.push(un); return un }

  const scopedBot = Object.create(this) as Bot
  scopedBot.command = track(this.command.bind(this))
  scopedBot.when = track(this.when.bind(this))
  scopedBot.onMessage = track(this.onMessage.bind(this))
  scopedBot.onType = track(this.onType.bind(this))
  // before/after/onError devuelven this — versión tracked que registra el unsubscribe del HookSystem:
  scopedBot.before = (e, h, p = 0) => { disposables.push(this.hooks.register(e, 'before', h, p)); return scopedBot }
  scopedBot.after = (e, h, p = 0) => { disposables.push(this.hooks.register(e, 'after', h, p)); return scopedBot }
  scopedBot.onError = (e, h) => { disposables.push(this.hooks.register(e, 'error', h, 0)); return scopedBot }

  const ctx = {
    bot: scopedBot,
    logger: this.logger.child({ plugin: spec.name }),
    tools: this.tools,
    config: config ?? {},
    onDispose: (fn: () => void) => disposables.push(fn),
  }
  spec.install(ctx as never, config as never)
  return () => { while (disposables.length) disposables.pop()!() }
}
```
