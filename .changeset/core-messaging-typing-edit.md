Add automatic typing indicator (`BotConfig.typing`), per-reply pacing (`ctx.reply(text, { typing, delay, cancelIf })` on `reply`/`say`/`answer`/`text`/`quote`), `ctx.edit()` for the context's own last reply or a given ref (native via `provider.editMessage`, falling back to a new message in the ref's chat), `ctx.react(emoji, target?)` that resolves `skipped` on providers without reaction support, and `ctx.supports(feature)` reporting `native` / `degraded` / `unsupported`. A failing typing indicator never fails a send; an explicit per-reply `maxMs` below the bot's `minMs` lowers the minimum instead of throwing. Edits run through the `before`/`after('send')` hooks (payload carries `edit: ref`, hooks can rewrite or abort them) and update the outbound ledger. `ctx.edit(content)` only targets the same context's last reply of the same kind (never another handler run's or another participant's flow); a later `bot.send`/`bot.sendTo` to the chat invalidates it. A paced reply is dropped (`skipped`) when the bot stops, the chat is handed off or the flow is aborted during its wait, and `stop({ drain: true })` waits for paced replies.
