Testing kit: `createTestBot()` closes the conversation-assertion gaps. The chat gains `expectNoReply({ timeout })`, `sendMedia(kind, bytes | { url }, caption?)` (downloads resolve with the bytes; `{ url }` alone rejects with `MediaUnavailableError`), `sendReaction(emoji, ref?)`, `sendLocation(lat, lng)`, `pressButton(id | title | index)` for native buttons, list rows and card buttons, `sendInteraction(data, { kind })`, `sent()` / `lastReply()`, `chatId` / `senderId` / `isGroup` / `displayName` (`jid` stays as a deprecated alias) and `transcript()`, a golden `Transcript` with the same shape `recordTranscript` produces (stable for `toMatchSnapshot()`, replayable with `assertTranscript`, `as: 'text'` for a readable rendering). Typed multi-user views: `dm(userId)`, `group(groupId, { as })` and `chat.as(userId)`. `MockProvider` adds a chronological `journal` (inbound + sends with their `ref`, bounded by `maxJournal`), `incomingMedia()`, `reaction()`, `interaction(data, { kind })` and a real `downloadMedia(ref)`; `outbox` is unchanged. New optional subpath `@bot-wa/core/testing/vitest` with `botMatchers` (`toHaveReplied`, `toHaveRepliedMatching`, `toHaveRepliedTimes`) for `expect.extend`; `vitest` becomes an optional peer dependency (never imported at runtime). `chat.replies()` now reports a card's title as its text.
