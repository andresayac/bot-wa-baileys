Add a dynamic flow registry to `Bot`: `registerFlow()`, `unregisterFlow()`, `replaceFlow()` (hot-swap), `hasFlow()`, `listFlows()`, `triggerFlow()` (start a flow proactively in a chat) and `listConversations()`. New exported types `RegisteredFlowInfo`, `FlowTriggerTarget` and `FlowTriggerOptions`.
